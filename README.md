# 麦回本

> 算清楚再决定，不划算就别买。用你自己的点餐记录，算出【麦金卡】到底值不值得买。

非官方、只读、零依赖（仅 Python 标准库）。基于[麦当劳中国 MCP](https://open.mcd.cn/mcp)。

## 项目介绍

麦金卡（随单购月卡）宣传“下单立减”，但到底划不划算，取决于你**自己**多久点一次、点什么。

麦回本把你最近的订单取出来，用官方价格计算器分别算“不带卡”和“带卡”的价格，扣掉卡费后给出：

- 每单能省多少
- 近期累计净节省
- 30 天预测节省（预测，非保证）
- 每 30 天需要几单才回本
- 明确结论：值得买 / 不值得买 / 边缘（再观察）

不划算就直说“不建议购买”。

## 目标用户

- 正在犹豫要不要买麦金卡的麦当劳顾客
- 想让智能体（WorkBuddy / Kiro / Claude 风格的 Skill）帮自己做消费决策的人
- 想学习如何把 MCP 工具组合成实用小工具的开发者

## 结论

**值得买**：按近期频率折算，30 天预计节省 ¥39.13，高于卡费 ¥19.00 的 1.2 倍门槛。

## 汇总

- 可用订单：12 / 15（跳过 3）
- 统计跨度：23 天
- 月卡卡费（30 天）：¥19.00（取自试算结果，以实际为准）
- 有卡更省 / 持平 / 更贵的订单：11 / 1 / 0
- 跨度内累计节省（未扣卡费）：¥30.00
- 跨度内净节省（累计节省 − 一张卡费）：¥11.00
- 30 天预测节省（预测，非保证）：¥39.13
- 平均每单节省：¥2.50
- 回本所需：约每 30 天 7.6 单同类订单

## 注意事项

- 回放使用的是【今天】的菜单、价格和门店，不是你当时实际支付的价格。
- 套餐按默认组成（productCode）回放，不还原你当时的自选替换。
- 已下架/当前门店不可售的商品会被跳过并注明原因。
- 订单列表仅返回最近约 10 单，样本小，结论请当作参考；样本不足会被标记。
- 目前只回放到店点餐（含得来速）；麦乐送订单会被跳过。
- 身份类折扣（如员工卡）与随单购麦金卡优惠不叠加：若检测到，本工具不给出买/不买结论。
- 30 天节省额是按近期频率折算的【预测】，不是保证。
- 本工具只读，不会下单或开通任何卡。

_早餐卡相关为实验功能，见 `breakfast` 子命令，不提供购买建议。_

### 身份折扣场景（`--demo analyze --scenario identity`，同样为虚构数据）

当基准价已含身份折扣（如员工卡）时，工具不会给出买/不买结论：

**无法判断（已有身份折扣）**：你的账号已享受【示例员工卡 7.5折】，它与随单购麦金卡优惠不叠加，试算时有卡价格反而更高，所以这次结果不代表普通用户的情况，也不建议据此购买；如需判断，请用没有身份折扣的账号或咨询门店。

## 如何工作

1. 读取：`order-list` 取最近订单，只保留到店（含得来速）且未取消的订单。
2. 发现：按门店调用一次 `query-meals`，在运行时获取随单购麦金卡的会员参数。
3. 回放：每单用 `calculate-price` 算两次（不带卡 / 带卡），从结果里的卡费行得到卡费，汇总并给出结论。

结论规则：30 天预测节省 ≥ 卡费 × 1.2 且可用订单 ≥ 5 单为“值得买”；预测节省低于卡费为“不值得买”；其余为“边缘/再观察”。阈值可用 `--margin`、`--min-orders` 调整。若任一订单的不带卡结果里已含身份折扣（`enjoyed`），则结论固定为“无法判断（已有身份折扣）”。卡费每次从试算结果中读取（不假定固定值），多单不一致时取中位数并标注范围。

## 安装方法

把整个文件夹复制到智能体的 skills 目录即可：

```bash
# 例：Kiro / WorkBuddy / Claude 风格的 skills 目录（路径以你的客户端为准）
cp -r mc-breakeven <你的 skills 目录>/mc-breakeven
```

脚本通过 HTTP 直接访问 MCP。如果你的客户端也想以 MCP 方式接入同一服务，可参考 `mcp-config.example.json`（Token 取自环境变量 `MCD_MCP_TOKEN`）。

### 设置 Token

先到 <https://open.mcd.cn/mcp> -> 登录 -> 控制台 -> 激活，获取 MCP Token，然后只在终端环境变量里设置：

```bash
# macOS / Linux
export MCD_MCP_TOKEN="你的Token"
```

```powershell
# Windows PowerShell
$env:MCD_MCP_TOKEN="你的Token"
```

不要把 Token 写进仓库或任何文件。未设置时，脚本会给出中文提示并以退出码 2 结束。

## 诚实的局限

- 回放使用**今天**的菜单、价格和门店，不是你当时实际支付的价格。
- 套餐按默认组成回放，不还原自选替换。

- 目前只回放到店点餐（含得来速），麦乐送订单会被跳过。
- **身份折扣不叠加（重要）**：若你的账号已有身份类折扣（如员工卡 7.5 折），它与随单购麦金卡优惠不叠加，带卡后价格反而可能更高。此时工具会给出结论【无法判断（已有身份折扣）】，不判定值得买/不值得买，也不建议据此购买；请用没有身份折扣的账号或咨询门店。
- 30 天节省额是按近期频率折算的预测，不是保证。
- 早餐卡为实验功能：MCP 暂未开放早餐卡购买参数，只展示价差（潜在、未验证），不提供购买价格或建议。
